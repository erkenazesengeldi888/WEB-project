About this project

I created this website about Espresso Day using HTML. First, I created the main HTML files and organized them in one project folder. I also created an images folder for my own photographs. I used semantic HTML elements such as header, nav, main, section, article, and footer to organize the pages. I added information about Espresso Day, its menu, coffee, and other services. I also added images, links, lists, tables, and a form. I used relative links to connect the pages of the website. I checked the structure of my HTML files and corrected mistakes while working on the project. The website does not use CSS or JavaScript because the assignment requires HTML only.

HTML example

I used the figure element to add a photo with a caption.

<figure>
    <img src="images/photo.jpg" alt="description">
    <figcaption>caption</figcaption>
</figure>

Keyboard input
